  # 🚀 Personal Portfolio Website

A sleek, dynamic, and fully responsive developer portfolio built with **React** and modern CSS. Designed with a dark glassmorphic theme, smooth scroll reveal animations, and a functional contact form powered by **Web3Forms**.

---

## ✨ Features

- **🎨 Modern Dark UI:** Styled with sleek gradients, glassmorphic navigation, and glowing accents.
- **📱 Fully Responsive:** Optimized for desktop, tablet, and mobile displays.
- **⚡ Interactive Scroll Animations:** Utilizes native `IntersectionObserver` for efficient, buttery-smooth scroll reveals.
- **📬 Working Contact Form:** Integrated directly with **Web3Forms** for instant email delivery without requiring a backend server.
- **💻 Dynamic Projects Showcase:** Highlighted cards featuring project descriptions, tech stacks, and live demo links.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3 (Custom CSS Variables & Flexbox/Grid)
- **Email Service:** Web3Forms API
- **Deployment:** Vercel / Netlify
- **Version Control:** Git & GitHub
